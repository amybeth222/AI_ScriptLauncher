# Script Launcher — Privacy Policy & Terms of Service

_Last updated: August 2026_

## Privacy Policy

Script Launcher does not collect, store, transmit, or share any personal data, usage analytics, or telemetry of any kind.

- The panel reads only the local folder path you explicitly choose, to list `.jsx`/`.jsxbin` script files within it.
- Your folder selection and display preferences (text size, colors, spacing, script order) are stored **locally on your machine only**, in Illustrator's local extension storage (`localStorage`). This data never leaves your device.
- Script Launcher makes no network requests and does not communicate with any external server.
- Scripts you choose to run are executed locally via Illustrator's built-in ExtendScript engine (`$.evalFile()`), exactly as if you had run them via File > Scripts.
